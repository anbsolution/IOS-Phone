# iOS Phone

iOS 17 inspired native Android dialer.

## Technology
- Kotlin
- Jetpack Compose
- Material 3
- Android Telecom (planned)

## Phase 1
- iOS-inspired keypad
- Favorites screen
- Recents screen
- Contacts screen
- Voicemail screen
- Bottom navigation

## Planned
- Default Phone role
- Incoming call interface
- Ongoing call interface
- Dual SIM support
- Call history integration

Real calling functionality is not yet implemented.
